# Rainworks | 企画・検討・決定ノート
最終更新: 2026-11-16  
状態: 初期プロトタイプ

## 企画
地形と建物を重ねた街区に雨を降らせ、雨水が集まり、流れ、低地にたまる様子をブラウザ上で観察できる体験を作る。利用者は地図から対象地点を選び、1 km四方のメッシュに入って雨量と粒子数を調整する。

## 想定利用者・体験
防災や都市環境を学ぶ人が、地形と雨水の関係を視覚的に理解する。地図をクリック、または地名検索してメッシュを選択。標高・建物を読み込んで3D表示し、雨量と粒子数を調整して再生する。ドラッグで視点を回し、ホイールで拡大縮小して街区を観察する。

## 決定事項
| 項目 | 決定 |
|---|---|
| 配布形態 | ブラウザアプリ + Python標準ライブラリのローカルサーバー。外部データはローカルディスクへキャッシュ |
| 地図 | Leaflet + OpenStreetMapタイル。タイルはローカルプロキシ経由で取得し、HTTPキャッシュ指示に従って保存 |
| 地形 | 日本国内は国土地理院の標高PNGタイル（DEM5A→DEM5B→DEM5C→DEM10B）、国外はOpen-Meteo Elevation API（Copernicus DEM GLO-90由来）。取得できない標高は代替APIまたは近傍補間 |
| 建物 | OpenStreetMapのbuilding=*ポリゴンをOverpass APIから取得し、成功レスポンスを24時間キャッシュ |
| 3D | Three.js WebGL。地形高低差、建物押し出し、降雨粒子、水深と流向を表示 |
| メッシュ | 選択点を中心とする東西南北各500 mの正方形（緯度に応じて経度幅を補正） |
| 水理モデル | 地形標高とセル水深から近傍への勾配流を近似する教育・可視化用の簡易モデル |
| 建物 | 建物フットプリントを地表セルから除き、水を蓄積させない |
| データ帰属 | 国土地理院、Open-Meteo / Copernicus、OpenStreetMap contributorsを画面で明示 |

## 前提・限界
- 降雨、地形勾配、セル間移動、建物遮蔽を可視化する簡易モデル。浸水予測や避難判断に使う工学的な水理解析ではない。
- 国土地理院の標高タイルは場所により利用可能なDEM種別と解像度が異なる。国外のOpen-Meteoデータは概ね90 m級を32 m間隔へ補間するため、街路や側溝の微地形は再現できない。
- OSM建物の登録状況は地域差があり、未登録建物は遮蔽されない。
- 公開APIの可用性・混雑・利用条件に依存する。標高取得は逐次リクエストと再試行を行い、建物取得は複数の公開Overpassインスタンスへ順にフォールバックする。
- APIの応答や利用条件が変わる可能性があるため、公開運用前に各提供元のポリシーを確認する。ローカルキャッシュがなく初回の外部取得に失敗した場合は画面に取得元を表示する。

## 機能
1. 地図で地点を選び、1 kmメッシュと中心を表示。
2. 地名検索で地図を移動。
3. 標高面、建物、落下する雨粒、地表を低地へ動く水粒子と短い軌跡を3D表示。ドラッグ・ズームで視点変更。
4. 雨量5–150 mm/h、雨粒数200–3,500を調整。地表水粒子数は設定した雨粒数に連動。
5. 再生・停止・初期化と経過時間表示。
6. 建物フットプリントは水深更新と地表粒子の経路から除外。

## 起動方法（WSL2 / Ubuntu）

このプロジェクトは `/home/yukio/projects/t5` にある前提。Ubuntu（WSL2）のターミナルからローカルサーバーを起動する。

```bash
cd ~/projects/t5
python3 server.py
```

サーバー起動後、Windows側のブラウザで http://localhost:8000 を開く。8000番ポートが使用中なら、古いサーバーのターミナルで `Ctrl+C` を押して停止するか、別ターミナルで `python3 server.py --port 8001` を実行して http://localhost:8001 を開く。終了するときはサーバーを起動したターミナルで `Ctrl+C` を押す。Pythonの標準ライブラリのみを使うため、追加パッケージのインストールは不要。

## ローカルデータキャッシュ

キャッシュは `.cache/rainworks/` にバイナリ本体と期限情報を保存する（Git管理対象外）。ブラウザは標高タイル、標高API、建物データ、地図タイル、地名検索のすべてを同じローカルサーバー経由で取得する。

| データ | キャッシュ期間 |
|---|---:|
| 国土地理院標高タイル | 30日 |
| Open-Meteo標高応答 | 30日 |
| OpenStreetMap建物ポリゴン | 24時間 |
| OpenStreetMap地図タイル | 提供元のHTTP指示を優先。指示がない場合は7日 |
| Nominatim地名検索 | 30日（未キャッシュ検索は1.1秒以上間隔を空ける） |

有効期限内はキャッシュを返す。期限切れ後に提供元へ接続できない場合は、保存済みの古い応答を利用する。初回取得で提供元に接続できない場合はデータを表示できない。キャッシュを消すときはサーバーを停止し、Ubuntuで `rm -rf .cache/rainworks` を実行する。

地図タイルは表示中に要求されたものだけをキャッシュし、先読みや一括取得は行わない。OpenStreetMapのタイル利用条件に従い、HTTPキャッシュ指示を尊重する。

## 接続トラブル

ローカルサーバーのコンソールに `[cache] MISS` が出るのは外部から初回取得中、同じデータで `HIT` が出るのはローカルキャッシュ利用中。外部APIが失敗しても期限切れキャッシュがあれば `STALE` として返す。接続できない場合は、起動ログと画面のデータ取得エラーを確認する。
